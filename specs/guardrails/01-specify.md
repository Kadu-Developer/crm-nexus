MUST:
- Read real repository evidence before claiming current state.
- First feature invokes `find-skills` before implementation.
- Define objective, scope, business rules, edge cases, acceptance criteria and out-of-scope.
- Distinguish fact, hypothesis and future decision.

- install runtime dependencies;
- create migrations;
- expand the feature into unrelated work.
PASS only when every acceptance criterion is objectively testable.
