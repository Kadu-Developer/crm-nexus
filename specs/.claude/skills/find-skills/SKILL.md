# Procedure
1. Read `specs/SKILLS-POLICY.md`, `SKILLS-CATALOG.md`, `SKILLS-AUDIT.md`, `SKILLS-RESOLUTION.md`.
2. Inspect project and personal Claude skills actually available.
3. Match required capability to current feature/stage.
4. Audit third-party skills using `specs/guardrails/00-skill-supply-chain.md`.
5. Update `SKILLS-RESOLUTION.md` only with verified skills.
6. Never claim a skill exists unless verified.
7. Return to the calling Spec Kit file.
