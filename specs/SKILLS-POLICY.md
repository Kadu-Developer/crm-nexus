# SKILLS-POLICY

1. The first feature MUST run `find-skills`.
2. Use verified/audited skills only.
3. Select the smallest relevant skill set per stage.
4. Testing is risk-based, not “unit tests only”.
5. Third-party skills are subject to `guardrails/00-skill-supply-chain.md`.
6. Built-in Claude capabilities may be used when a third-party skill is absent.
7. Never install or execute a skill merely because it appears in the catalog.
